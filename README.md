Task19-Duplicate Records and Data Validation

## Objective

The objective of this project is to detect duplicate records and perform basic data validation checks to identify inconsistent or invalid records.

## Tools Used

- Python
- Pandas
- Jupyter Notebook

## Dataset

Customer Personality Analysis Dataset

The dataset contains customer information such as customer ID, education, income, marital status, purchases, complaints, and campaign responses.

## Tasks Performed

- Loaded the customer dataset using Pandas
- Examined the dataset structure
- Checked for missing values
- Detected duplicate records
- Removed unwanted duplicate records
- Performed data validation checks
- Checked data types
- Checked customer IDs for duplicates
- Validated numerical values
- Created a cleaned dataset

## Duplicate Record Analysis

The duplicated() function was used to identify duplicate rows.

The drop_duplicates() function was used to remove unwanted duplicate records.

## Data Validation Checks

The following validation checks were performed:

1. Missing value check
2. Duplicate record check
3. Customer ID duplication check
4. Numerical value validation
5. Data type validation
6. Category validation
7. Range validation


## Conclusion

The Customer Dataset was analyzed for duplicate and invalid records. Various data validation
 checks were performed using Python and Pandas. Duplicate records were removed and a cleaned dataset was created for further analysis.
